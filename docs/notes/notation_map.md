## Локальные обозначения нашей курсовой

### Состояние пикселя `z[k]`

```
z[k] = (p[k], q[k]) ∈ ℝ²,
  p[k] — нормированное положение частицы (0 = у тёмного электрода,
         1 = у светлого),
  q[k] — остаточный заряд (proxy ghost), |q[k]| ≤ q_max.
```

### Управление `u[k]`

```
u[k] ∈ U = {VSH1, VSH2, VSL, VCOM, GND},
       соответствующие напряжения V(u[k]) ∈ {+15, +5, -15, 0, 0} В
       (типовые значения, см. § 3.5 для калибровки).
```

### Метрики (см. § 4.2)

```
E[k]    — энергия фазы k:  E[k] = (1/2) C ΔV[k]² f V(u[k]) · TP[k]
                                  (формула Lin 2024)
G(z[k]) — ghost-residual:   G = Σ_pix |reflect(z[k]) − reflect_target|
TP[k]   — длительность фазы k в frame'ах (1..255).
```

### Скаляризация (для ε-constraint в § 5.2)

```
J^ε(u) = α·E(u) + β·G(z) + γ·τ(u)
с фиксированными ε_G, ε_τ → задача
  min E(u)  s.t.  G(z) ≤ ε_G, τ(u) ≤ ε_τ, charge_balance(u) = 0.
```

## Технические тождества и соответствия

### От Понтрягина к Paruchuri

Непрерывная задача Понтрягина → дискретная задача Paruchuri через
прямую Эйлерову схему `x(t + Δt) ≈ x(t) + f(x, u, t)·Δt`. Гамильтониан
сохраняется, но adjoint dynamics превращается из ODE в разностное уравнение.

### От Paruchuri к нашей формулировке

Дискретное множество `U` (вместо `U_t ⊂ ℝᵐ`) — наше отличие. Tangent cone
из (PMP-v) Paruchuri вырождается в «список допустимых переходов»: из текущего
`u[k]*` в любое из 4 других значений. Hamiltonian maximization превращается в
*pointwise максимум по конечному множеству*, что и даёт bang-bang структуру.

### Charge balance vs frequency constraint

```
Paruchuri (формула 2.6):    DFT supp(û) ⊂ W   ⟺  F·u ∈ {0}^{T \ W}
Наша курсовая:              Σ V(u[k])·TP[k] = 0   ⟺  v^T · u = 0
                            где v ∈ ℝ^K, v[k] = V_diff(u[k])·TP[k]
```

Структурно одного типа (одно или несколько линейных равенств на
последовательность `u`), но наш случай — единственное скалярное равенство,
что упрощает технику. Constraint qualification для нашего случая —
`v ≠ 0` (тривиально для нетривиальных waveform'ов), что гарантирует
normal extremals (`η^C = 1`).

## Соглашения по индексам и шрифтам в курсовой

- Жирные строчные (`\bm{z}`, `\bm{u}`) — векторы.
- Жирные заглавные (`\bm{A}`, `\bm{F}`) — матрицы.
- Звёздочка (`u*`, `z*`) — оптимальные значения.
- Квадратные скобки `[k]` — дискретный индекс времени/фазы.
- Греческие буквы для множителей (`λ`, `ν`, `α`, `β`, `γ`, `ε`).
- Калиграфические для множеств (`\mathcal{U}`, `\mathcal{S}`).

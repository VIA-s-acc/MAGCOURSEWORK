## Постановка

Three-color EPD (b/w + red): красные частицы остаются в верхней части
микрокапсулы при grayscale transitions → «red ghost» effect. Цель — устранить.

## Метод — модифицированная 3-stage waveform

Традиционный waveform = erasing + activation + driving. Wang модифицирует:

1. **Sub-divided erasing:** разделение на (a) **red-specific erasing**
   (negative voltage VE1 для возврата красных частиц), (b) **original
   erasing** (стандартный).
2. **Activation** — high-frequency square wave (30 ms period, 30 cycles)
   для активации b/w частиц. Меньше flicker, потому что high freq.
3. **Driving** — стандартный.

## Физическая модель — Стоксова формула скорости

```
v = (Uq/(6πdηR)) · (1 − exp(-6πηR·t/m))
```

где:
- `U` — voltage, `q` — particle charge, `d` — distance, `η` — viscosity,
  `R` — particle radius, `m` — mass, `t` — time.

В пределе `t → ∞`: terminal velocity `v_∞ = Uq/(6πdηR)`.

## Результаты

- **Red ghost intensity −80.43%.**
- **Flicker −79.63%.**
- **Luminance (white) +20.8%** (improvement).
- Maintained **DC balance compliance** — явная проверка charge balance.

## Связь с нашей курсовой

### Физика для нашей ODE-модели (§ 3.4)
- **Стоксова формула** — основа для нашей mean-field редукции:
  `v = Uq/(6πdηR)·(1 − exp(-t/τ))` где `τ = m/(6πηR)`.
- Калибровка трёх параметров: `Uq/(6πdηR)` (terminal velocity ∝ V),
  `τ` (постоянная времени), `R` (геометрия).

### Hard-constraint charge balance (§ 4.3)
- Wang явно упоминают **DC balance compliance** — это нормативная практика
  в industry.
- Наш hard-constraint `Σ V·TP = 0` — формализация этой best practice.

### Не используем напрямую
- Red particles — не наш случай (b/w SSD1680).
- High-frequency activation (30 ms period × 30 cycles) — это частный случай,
  который выпадает из нашей оптимизации, потому что SSD1680 имеет более
  крупное временное разрешение (TP — это frame counts).

## Главы цитирования

- **§ 2.2 (Таксономия):** Wang — представитель ghost-reduction подходов.
- **§ 3.3 / 3.4 (Стокс):** прямое использование формулы скорости частицы.
- **§ 4.3 (Hard-constraint charge balance):** Wang явно упоминают как
  required practice.
- **§ 6 / 7 (Сравнение):** −80% ghost у Wang — agreed-upon целевой
  показатель для **ghost-only** оптимизации.

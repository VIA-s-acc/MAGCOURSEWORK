# Конспект: Васильев Ф.П. «Методы оптимизации» (2002)

Источник: `docs/refs/vasiliev2002_methods.pdf` (415 стр.). М.: Факториал Пресс, 2002. ISBN 5-88688-056-9.
Учебник кафедры оптимального управления ВМК МГУ.

**Замечание.** PDF — image-only (без text layer), OCR не выполнен. Этот файл —
структурированный skeleton, в который нужно вручную внести выписки из ключевых
разделов при подготовке глав 3-5 курсовой.

## Главы для нашей работы

Из общей структуры книги нам нужны главы 1-5 (фундамент методов оптимизации
в конечномерных пространствах) и глава 8 (мини-максные задачи / связь с
многокритериальной оптимизацией).

### Глава 1. Постановка задач математического программирования

**Что в главе (TOC по академическим традициям):**
- 1.1. Введение: классификация задач (безусловные/условные, линейные/нелинейные).
- 1.2. Постановка задачи: минимизация функционала `J(x) → min, x ∈ X ⊂ ℝⁿ`.
- 1.3. Существование решения: компактность, теорема Вейерштрасса.
- 1.4. Принципы релаксации, штрафных функций, регуляризации.

**Применение в курсовой:**
- § 4.1-4.3: формулировка нашей задачи как задачи мат. программирования
  с дискретным конечным множеством управлений `U = {VSH1, VSH2, VSL, VCOM, 0}`
  и hard-constraint `Σ V·TP = 0`.
- Конкретные ссылки на номера утверждений Васильева — ЗАПОЛНИТЬ ВРУЧНУЮ
  при чтении.

### Глава 5. Условия экстремума (необходимые и достаточные)

- 5.1. Необходимые условия первого порядка: `∇J = 0` (без ограничений).
- 5.2. Метод множителей Лагранжа (равенства).
- 5.3. **Условия Каруша-Куна-Таккера** (неравенства + равенства).
- 5.4. Условия второго порядка (положительная определённость Гессиана).
- 5.5. Связь с теорией двойственности.

**Применение в курсовой:**
- § 4.4: формулировка дискретного PMP (Понтрягина-Болтянского) как
  обобщения KKT на динамические задачи с дискретным управлением.
- § 4.5: использование условия максимума гамильтониана на каждом шаге
  как аналога KKT.

### Глава 8. Минимаксные и многокритериальные задачи

(Точное название может отличаться — уточнить по TOC при доступе к OCR-версии.)

- 8.1. Минимаксная задача: `max_y min_x f(x, y)`.
- 8.2. Связь с равновесиями (Нэш, седловые точки).
- 8.3. Многокритериальная оптимизация: Парето-оптимальность.
- 8.4. Скаляризация: weighted sum, ε-constraint, лексикографический подход.

**Применение в курсовой:**
- § 5.1-5.4: вся постановка как многокритериальная задача `(E, G, τ)`,
  построение Парето-фронта через ε-constraint метод.
- § 5.5: NSGA-II как альтернативный «слепой» подход + наше превосходство
  через структурную теорему 4.1.

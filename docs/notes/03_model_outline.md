## 3.1 Микрокапсула и электрофорез (~0.8 стр.)

**Цель:** дать минимально необходимое описание физического устройства EPD-пикселя
для введения уравнений §3.2.

**Содержание (4 абзаца):**

**Абзац 1 — структура микрокапсулы.**
- Сферическая капсула диаметром $d_{\text{caps}}\sim 40\ldots 50$~мкм.
- Внутри: непроводящая жидкость (углеводород с относительной проницаемостью $\varepsilon_m \approx 2{,}0$) + пигментные частицы радиусом $R \sim 100\ldots 500$~нм.
- Два типа частиц с противоположными знаками заряда (белые $\mathrm{TiO}_2$ — положительные, чёрные углерод — отрицательные).
- Цитата: `\cite{comiskey1998_nature, yang2021_mechanisms}`.

**Абзац 2 — приложение поля и движение.**
- Электроды сверху (общий ITO) и снизу (TFT-segmented).
- При $U \neq 0$ возникает электрофоретическая сила $\vec{F}_{\!\text{EP}} = q \vec{E}$.
- В установившемся режиме баланс с Stokes-сопротивлением даёт terminal velocity.

**Абзац 3 — Двойной слой и charge controlling agents.**
- CCA придают частицам зарядное состояние (механизм обмена в неполярной среде).
- Цитата: `\cite{yang2021_mechanisms}` (раздел про CCA).
- Это объясняет, почему в типовых режимах нашей курсовой можно считать заряд частицы $q$ константой (на временах одного refresh).

**Абзац 4 — диэлектрофорез как уточнение.**
- В неоднородном поле появляется $\vec{F}_{\!\text{DEP}} = 2\pi r^3 \varepsilon_m \text{Re}(K^*) \nabla |\vec{E}|^2$
  \cite{bert2003_physics}.
- В режиме настоящей работы (DC pulses со среднеравным нулю, без AC-составляющей)
  вклад DEP мал — это допущение **явно проговаривается** и подтверждается в гл.7.

## 3.2 Уравнения Нернста-Планка (PDE-уровень) (~1.8 стр.) — РАСШИРЕНО

**Цель:** **полный вывод** уравнений Нернста-Планка из первых принципов
(continuity + flux constitutive relation + Poisson), для математической
строгости работы ВМК.

**Содержание:**

**3.2.1. Уравнение непрерывности.**

Из закона сохранения числа частиц для каждого типа $\pm$:
$$\frac{\partial c_\pm}{\partial t} + \nabla \cdot \vec{J}_\pm = 0, \tag{3.1}$$
где $c_\pm(x, t)$ — числовая концентрация частиц, $\vec{J}_\pm$ — поток
(число частиц через единицу площади в единицу времени).

Это аксиоматическое уравнение, не зависящее от природы потока. Дальнейшая
конкретизация модели — в определении $\vec{J}_\pm$.

**3.2.2. Поток как сумма диффузионного и дрейфового компонентов.**

В системе с двумя движущими силами — градиентом концентрации
(тепловая диффузия) и электрическим полем (электрофорез) — поток имеет вид:
$$\vec{J}_\pm = -D_\pm \nabla c_\pm + c_\pm \vec{v}_\pm, \tag{3.2}$$
где $D_\pm$ — коэффициенты диффузии, $\vec{v}_\pm$ — дрейфовая скорость.

**Первое слагаемое** — Фиков закон диффузии для системы частиц в жидкости.
**Второе** — конвективный перенос с дрейфовой скоростью под действием поля.

**3.2.3. Стоксова дрейфовая скорость.**

Для шарообразной частицы радиуса $R$, заряда $q$ в жидкости вязкости $\eta$
в поле $\vec{E}$:
- Электрическая сила: $\vec{F}_E = q\vec{E}$.
- Сила сопротивления (закон Стокса): $\vec{F}_{\text{drag}} = -6\pi\eta R \vec{v}$.

В установившемся режиме ($\dot{\vec{v}} = 0$) баланс сил даёт:
$$\vec{v} = \frac{q\vec{E}}{6\pi\eta R} \equiv \mu_e \vec{E}, \tag{3.3}$$
где $\mu_e \equiv \frac{q}{6\pi\eta R}$ — \textit{электрофоретическая подвижность}.
Знак $q$ определяет направление: положительные частицы движутся по полю,
отрицательные — против.

С учётом знака заряда:
$$\vec{v}_\pm = \pm\mu_{e,\pm} \vec{E}, \qquad \mu_{e,\pm} \equiv \frac{|q_\pm|}{6\pi\eta R_\pm}. \tag{3.4}$$

**3.2.4. Связь Эйнштейна (соотношение диффузия-подвижность).**

В состоянии теплового равновесия флуктуационно-диссипационная теорема
устанавливает:
$$D_\pm = \mu_{e,\pm} \frac{k_B T}{|q_\pm|} = \frac{k_B T}{6\pi\eta R_\pm}. \tag{3.5}$$

Это формула Стокса-Эйнштейна. Подставляя в (3.5) численные значения
($T \approx 295$ К, $\eta \approx 10^{-3}$ Па·с, $R \approx 200$ нм),
получаем $D \sim 10^{-12}$ м²/с, что соответствует характерным значениям
для коллоидных систем.

**3.2.5. Замена поля потенциалом.**

Электрическое поле $\vec{E}$ выражается через скалярный потенциал
$\varphi(x, t)$:
$$\vec{E} = -\nabla \varphi. \tag{3.6}$$

Подстановка в (3.2)-(3.4):
$$\vec{J}_\pm = -D_\pm \nabla c_\pm \mp \mu_{e,\pm} c_\pm \nabla \varphi. \tag{3.7}$$

**3.2.6. Уравнения Нернста-Планка (итог).**

Подставляя (3.7) в (3.1) и учитывая постоянство $D_\pm, \mu_{e,\pm}$ в
объёме микрокапсулы (изотропная жидкость), получаем:
$$\boxed{\;\frac{\partial c_\pm}{\partial t} = \nabla \cdot \left(D_\pm \nabla c_\pm \pm \mu_{e,\pm} c_\pm \nabla \varphi\right).\;} \tag{3.8}$$

Это пара \textit{уравнений Нернста-Планка} для двух типов частиц,
выражающая баланс диффузии и дрейфа в потенциальном электрическом поле.

**3.2.7. Уравнение Пуассона.**

Система (3.8) не замкнута: $\varphi$ зависит от распределения заряда,
которое в свою очередь определяется $c_\pm$. Замыкание даёт уравнение
Пуассона:
$$-\nabla^2 \varphi = \frac{\rho_e}{\varepsilon_m \varepsilon_0}, \qquad \rho_e = e(c_+ - c_-), \tag{3.9}$$
где $\rho_e$ — объёмная плотность заряда, $\varepsilon_m$ — относительная
проницаемость несущей жидкости (для углеводородов $\varepsilon_m \approx 2$),
$\varepsilon_0$ — диэлектрическая постоянная.

Совместная система (3.8)-(3.9) образует задачу
\textit{Пуассона-Нернста-Планка} (PNP), являющуюся фундаментальной для
описания электрокинетических явлений в коллоидах и электролитах.

**3.2.8. Граничные условия.**

\textbf{На электродах} (Дирихле для $\varphi$):
$$\varphi(x = 0, t) = 0, \qquad \varphi(x = L, t) = U(t). \tag{3.10}$$

Где $U(t)$ — управляющее напряжение, прикладываемое контроллером SSD1680.
Это \textit{наш control variable} в последующей оптимизации (см. § 4).

\textbf{На электродах} (Нейман для потоков): отсутствие химической реакции
на электродах означает, что нормальный поток частиц равен нулю:
$$\vec{J}_\pm \cdot \hat{n} \big|_{x=0,L} = 0. \tag{3.11}$$

\textbf{Начальные условия:} однородное распределение в момент $t = 0$:
$$c_\pm(x, 0) = c_{\pm, 0} \equiv \frac{N_\pm}{V_{\text{caps}}}. \tag{3.12}$$

**3.2.9. Замечание о диэлектрофорезе и пренебрежении.**

Полная формулировка с диэлектрофорезом включала бы дополнительный член
$\sim \nabla \cdot \left(c_\pm \chi \nabla |\nabla\varphi|^2\right)$ в
правой части (3.8), где $\chi$ зависит от поляризуемости частиц
\cite{bert2003_physics}. В нашем режиме (DC-импульсы постоянного знака
в пределах фазы waveform, нулевое среднее) DEP-вклад мал по двум причинам:

1. Для DC-режима $|\vec{E}|$ практически постоянно в объёме капсулы
   (за исключением узких пограничных слоёв), что даёт $\nabla|\vec{E}|^2 \approx 0$.
2. Симметрия $V_{\text{SH}}$ и $V_{\text{SL}}$ в charge-balanced waveform
   приводит к взаимному погашению DEP-эффектов на временах одного
   обновления.

Подробное обоснование пренебрежения дано в \cite{bert2003_physics}, § 2.5;
в нашем рассмотрении DEP-эффекты не учитываются, что подтверждается
согласованием модели с экспериментом в гл. 7.

## 3.3 Mean-field редукция к ODE одного пикселя (~1.5 стр.)

**Цель:** показать корректность перехода от PDE к ODE через усреднение по
сечению микрокапсулы. Это самый математически нагруженный раздел.

**3.3.1. Допущения mean-field редукции.**

Три ключевых допущения, каждое **явно** проговорено:

1. **Symmetric capsule:** микрокапсула приближается сферическим объёмом с
   1D-осью симметрии $x \in [0, L]$. Это сводит 3D-задачу к 1D.
2. **Lumped position:** концентрация частиц каждого типа приближается
   $\delta$-распределением около центра масс $\bar{x}_\pm(t)$. Тогда:
   $$\bar{x}_\pm(t) = \frac{\int_0^L x \cdot c_\pm(x,t) \, dx}{\int_0^L c_\pm(x,t) \, dx}.$$
3. **Quasi-static potential:** $\varphi(x,t)$ устанавливается мгновенно по
   текущему распределению $c_\pm$ (характерное время RC-релаксации ≪ времени
   движения частиц).

**3.3.2. Получаемая ODE (после редукции).**

Интегрированием уравнений §3.2 по $x$ с учётом допущений получаем:
$$m_\pm \frac{d^2 \bar{x}_\pm}{dt^2} = q_\pm U(t)/L - 6\pi\eta R \frac{d\bar{x}_\pm}{dt},$$

или, переходя на скорости (overdamped режим):
$$\frac{d \bar{x}_\pm}{dt} = \frac{q_\pm U(t)}{6\pi\eta R L},$$

что и есть классическая электрофоретическая dynamics.

**3.3.3. Параметр reflectance.**

Отражательная способность пикселя как функция позиции белых частиц:
$$\rho(\bar{x}_+) = \rho_{\min} + (\rho_{\max} - \rho_{\min}) \cdot \frac{\bar{x}_+ - x_{\text{bot}}}{x_{\text{top}} - x_{\text{bot}}}.$$

(Линейное приближение; для tracking-уровневой точности модель ray-tracing
не нужна.)

схема редукции «PDE концентраций $\to$ ODE центров масс $\to$ дискретная LUT».

## 3.4 Стоксова форма для одной частицы (~0.7 стр.)

**Цель:** Связать общую ODE-модель с конкретными формулами, цитируемыми в
литературе (Wang 2022, He 2020), и подготовить базу для калибровки в §3.5.

**Содержание:**

**3.4.1. Дифференциальное уравнение Newton-Stokes.**

Для одной частицы массой $m$ в поле $U/L$:
$$m \frac{dv}{dt} = q \frac{U}{L} - 6\pi\eta R \, v$$
(He 2020, формула 3 \cite{he2020_particle_activation}).

**3.4.2. Аналитическое решение.**

При постоянном $U = \text{const}$:
$$v(t) = v_\infty \cdot \left(1 - e^{-t/\tau_{\text{Stokes}}}\right),$$
где:
$$v_\infty = \frac{q U}{6\pi\eta R L} \quad \text{(terminal velocity)}, \qquad \tau_{\text{Stokes}} = \frac{m}{6\pi\eta R} \quad \text{(время релаксации Стокса)}.$$

(Идентично формуле Wang 2022 \cite{wang2022_red_ghost}, с переобозначением.)

**3.4.3. Положение частицы.**

Интегрированием:
$$\bar{x}(t) = \bar{x}(0) + v_\infty \cdot \left(t - \tau_{\text{Stokes}}(1 - e^{-t/\tau_{\text{Stokes}}})\right).$$

**3.4.4. Что нам нужно откалибровать.**

В правой части ODE присутствуют **три эффективных параметра** (после reduction):
- $v_\infty / U$ — эффективная электрофоретическая подвижность (выражается через $\frac{q}{6\pi\eta R L}$);
- $\tau_{\text{Stokes}}$ — время релаксации (выражается через $\frac{m}{6\pi\eta R}$);
- $\rho(\bar{x})$ — функция «положение → reflectance» (линейная при наших допущениях).

Эти три параметра калибруются по эксперименту в §3.5. **Не пытаемся раздельно
оценить** $q$, $\eta$, $R$ — это переопределённая задача без специальных
измерений; достаточно их комбинаций.

## 3.5 Калибровка параметров по данным стенда (~1.5 стр.)

**Цель:** Подставить в полученную ODE реальные числа, замеренные на нашем
стенде через BENCH_RUN (опкод 0x0E).

**Содержание:**

**3.5.1. Экспериментальная установка.**

- Стенд: ESP32 + Waveshare 2.13'' V4 (SSD1680) + INA219.
- Калибровочный sweep: single-phase LUT с одним из $V \in \{V_{\text{SH1}}, V_{\text{SH2}}\}$
  на длительность $\text{TP} \in \{5, 10, 20, 50\}$ кадров, $n_{\text{repeats}} = 10$.
- Сохранение INA-трасс $(t, U, I, P)$ в CSV через `scripts/calibration_sweep.py`.
- Обработка в `notebook/01_calibration.ipynb`.

**3.5.2. Фитинг параметров.**

Метод: scipy.optimize.curve_fit на функцию

$$I(t) = I_\infty \cdot (1 - e^{-t/\tau}) + I_{\text{base}}$$

(аналог напряжения — поскольку ток пропорционален скорости движения частиц).

Из фита извлекаются:
- $\tau_{\text{Stokes}}^{\text{est}}$ — постоянная времени по току;
- $I_\infty^{\text{est}}$ — стационарный ток (пропорционален $v_\infty$).

Расхождения интерпретируются как effect of (i) разной геометрии микрокапсулы,

**3.5.5. Применимость модели — заключительный параграф.**

Явное проговаривание: ODE-модель валидна для **single-phase** waveform с
постоянным $U$. Для многофазных waveform с быстрыми переключениями
(когда время фазы $T_k < \tau_{\text{Stokes}}$) могут потребоваться поправки.
Для нашей задачи (charge-balanced waveform с $T_k \gtrsim \tau$) модель
достаточно точна, что подтверждается в гл.7 на полных измерениях B0..B4.

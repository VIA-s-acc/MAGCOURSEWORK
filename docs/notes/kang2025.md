## Постановка задачи (как у Kang)

EPD: контролируемые электрическим полем заряженные частицы в микрокапсуле,
b/w + цветные. Цель: устранить ghost, flicker, длинное response time.
Тип панели: **16-level grayscale print-style color EPD** (не b/w, как у нас).

## Метод (краткая суть)

1. **Optical simulation** через ray tracing для генерации training-set:
   расчёт `(V, T) → brightness` для разных уровней напряжения и длительности.
2. **Initial state:** G0 (полностью чёрный, после erase-flash).
3. **State transition equation**: `(G_current → G_target)` за серию шагов,
   каждый шаг = пара `(V, T)` (voltage level и time phase).
4. **Cost function** (формула в статье — скаляризованная):
   - `α·T + β·flicker + γ·image_quality` (примерно),
   - **веса α=0.6, β=0.2, γ=0.2** (image quality + flicker delegated to 0.4).
5. **Dynamic programming** для поиска **оптимального пути** через state space.
6. **Backtracking** от целевого состояния обратно к initial для восстановления
   waveform.

## Экспериментальная установка

- Indoor dark room + 2 table lamps (indirect lighting, чтобы не мешать).
- **Colorimeter** для замера яркости (t₁ = B→W transition, t₂ = W→B).
- Тестовая панель — 16-level color EPD.

## Заявленные результаты

- Сокращение response time (без конкретных %, см. Figure 9 в статье).
- Сокращение ghost (визуальная оценка colorimeter + numerical).
- Снижение flicker.
- **НЕТ количественной таблицы с энергией!** (это упущение для нашего сравнения
  — энергия Kang явно не оптимизирует).

## Связь с нашей курсовой и ключевые отличия

### Что у нас совпадает с Kang
- Дискретизация состояний пиксели и применение DP-ish optimization.
- Конечное множество управляющих уровней `(V, T)`.

### Что у нас принципиально РАЗЛИЧАЕТСЯ (наша новизна)

| Аспект | Kang 2025 | Наша работа |
|---|---|---|
| **Цели** | Скаляризация `α·T + β·flicker + γ·quality` с фиксированными весами | Полная **Парето-граница** (E, G, τ) без скаляризации (ε-constraint) |
| **Теоретическое обоснование** | Heuristic DP, без структурной теории | **Структурная теорема** (bang-bang, K_eff ≤ d_state + 2) на базе дискретного PMP |
| **Constraint** | Не упоминается charge balance явно | **Hard charge balance** `Σ V·TP = 0` (физически обоснован, см. Wang 2022, Lin 2024) |
| **Энергия** | НЕ оптимизирует и НЕ замеряет (только время+качество) | E = ∫U·I dt через INA219, явная цель оптимизации |
| **Тип панели** | 16-level color EPD | b/w SSD1680 Waveshare 2.13" V4 |
| **Симулятор** | Optical ray tracing (для калибровки brightness) | ODE-модель частиц (Стокса, Wang 2022) + surrogate |
| **Бенчмарк** | Без явного сравнения с другими методами | Парето строго доминирует ≥3 baseline'а (B0..B4) |

### Что мы используем как baseline-точку из Kang
- Сравниваем с их подходом на нашей панели: их **скаляризованный DP** должен дать **одну точку** на нашем Парето-фронте. Если она внутри нашего фронта — наша работа строго лучше.

### Контр-аргумент против критики «вы перепридумали DP»
- Наш дискретный PMP **не эквивалентен** их DP: PMP даёт структурный результат
  (форма оптимума, без полного перебора), DP даёт алгоритмический результат
  (численная процедура поиска).
- DP-based методы (как у Kang) могут найти only **локальный оптимум** в state space.
  Наш PMP гарантирует, что найденная bang-bang структура — глобально оптимальна
  в классе charge-balanced waveforms.

## Главы цитирования в курсовой

- **§ 1 (Введение):** упоминание как «современного конкурирующего подхода».
- **§ 2.2 (Таксономия waveform-методов):** Kang — представитель DP-based семейства.
- **§ 2.4 (Gap analysis):** **основное место**: эксплицитное сравнение нашего
  N1+N2 подхода с их N3 (бенчмарк + эвристика).
- **§ 5.4 (Алгоритм):** сравнение сложности нашего ε-constraint+PMP с их DP.
- **§ 6.4 / 7.4 (Симуляция и эксперимент):** воспроизводим их подход как
  одну точку Парето-границы, если найдём их config достаточно подробно.

## Формулировка Теоремы 4.1 (черновая)

Пусть `J: \mathcal{U} \to \mathbb{R}` — функционал стоимости

$$J(u) = \alpha \, E(u) + \beta \, G(z(u)) + \gamma \, \tau(u),$$

где `α, β, γ > 0` — фиксированные веса, `E, G, τ` — энергия, ghost-residual
и латентность waveform `u = (u[k])_{k=0}^{K-1}`, `u[k] \in U = \{V_{SH1}, V_{SH2}, V_{SL}, V_{COM}, 0\}`,
`K ≤ K_{max} = 12` (ограничение SSD1680).

Рассмотрим задачу:
$$\min_{u \in \mathcal{U}_{cb}} J(u), \qquad \mathcal{U}_{cb} := \left\{u : \sum_{k=0}^{K-1} V(u[k]) \cdot TP[k] = 0 \right\}.$$

**Теорема 4.1 (структура оптимума).** Оптимальное `u^* \in \mathcal{U}_{cb}` (если существует) обладает свойствами:
1. (**Bang-bang**) `u^*[k]` принимает значения только в множестве
   *активных вершин* `U_{active} \subseteq U`, мощность которого ≤ 4
   (исключая VCOM/GND в качестве «пассивного» уровня).
2. (**Bounded switching**) число фаз `k`, на которых `u^*[k] \neq u^*[k+1]`
   («переключений»), не превосходит `K_{eff} = d_{state} + 2`,
   где `d_{state}` — размерность пространства состояний пикселя.

В нашем случае `d_{state} = 2` (положение частицы + остаточный заряд) → `K_{eff} ≤ 4`.

## Дорожная карта доказательства

### Шаг 1. Перенос на дискретную PMP

Применяем Theorem 3.1 из Paruchuri & Chatterjee 2019 к нашей задаче:
- `x_t \to z[k]`, `u_t \to u[k]`, динамика `z[k+1] = F(z[k], u[k])`
  (Эйлерова дискретизация ODE-модели из § 3).
- Стоимость на шаге: `c_k(z, u) = \alpha \cdot E_k(u) + \beta \cdot \Delta G_k(z) + \gamma \cdot TP[k]`,
  где `E_k(u) = \tfrac{1}{2} C (\Delta V[k])^2 f V(u) \cdot TP[k]` (Lin 2024).
- Constraint: `Σ V(u[k]) TP[k] = 0` — одно линейное равенство.

**Замечание.** В Paruchuri это «frequency constraint» в DFT-форме `\widehat{u} \in F^{(k)}`.
У нас структурно проще: одно скалярное равенство `v^\top u = 0`, где
`v[k] = V_{diff}(u[k]) TP[k]`. Это укладывается в их формулировку как
1-мерное подпространство constraints (`\ell = 1` в их нотации).

Гамильтониан:
$$H_k(\lambda, z, u) = \langle \lambda, F(z, u) \rangle - \nu_k \, c_k(z, u) - \mu \cdot V(u) \cdot TP[k],$$
где `λ` — сопряжённая переменная, `ν_k ∈ \{0, 1\}` (normal vs abnormal),
`μ` — множитель Лагранжа для charge balance.

По Theorem 3.1 Paruchuri:
- (PMP-iii) **Adjoint dynamics:** `λ[k-1] = ∂H_k / ∂z` — линейное по `λ`
  разностное уравнение.
- (PMP-v) **Hamiltonian maximization:** `u^*[k] ∈ \arg\max_{u \in U} H_k(\lambda[k], z[k], u)`.
- (PMP-vi) **Charge balance:** `Σ V(u^*[k]) TP[k] = 0`.

### Шаг 2. Bang-bang из дискретности U

Поскольку `U` — конечное множество (5 элементов), `\arg\max_{u \in U} H_k` —
тоже элемент `U`. Это автоматически даёт bang-bang в смысле:
*оптимальное управление в каждой фазе — один из 5 уровней source, не среднее*.

Для исключения «пассивного» VCOM/GND из bang-bang активных вершин:
- В Hamiltonian'е член `\langle \lambda, F(z, VCOM) \rangle = 0` (VCOM не двигает
  частицу — её слагаемое в Стоксовой модели даёт `v ∝ V = 0`).
- Член `c_k(z, VCOM) = 0 + β·ΔG_k(z) + γ·TP[k]` — стоит чистого штрафа за
  время без выгоды.
- Поэтому VCOM выбирается только в фазах, где «выгоднее простоять», что
  ограничивает их число (см. Шаг 3).

### Шаг 3. Bound на число переключений

Воспользуемся аналогом Pontryagin §3.3 («теорема об n переключениях для
линейных систем») в адаптации Paruchuri.

**Ключевое наблюдение.** Множество индексов `k`, где Hamiltonian
*меняет* `\arg\max` (т.е. происходит switching), соответствует моментам,
когда несколько `u \in U` дают одинаковый `H_k`. По условию максимума
это происходит только когда `λ[k]` лежит на пересечении конусов,
разделяющих кандидатов.

Поскольку `λ` эволюционирует по линейному разностному уравнению
(Шаг 1, PMP-iii), её траектория лежит в подпространстве размерности
`≤ d_{state}` = 2. Hyperplane'ов разделения между парами `u_i, u_j \in U`
максимум `C_5^2 = 10`, но эффективно пересекаются только те, что
содержат «оптимизационный отрезок» траектории `λ[k]`.

**Лемма (бенчмарк):** число переключений `≤ d_{state} + |constraints| + 1 = 2 + 1 + 1 = 4`.

Это даёт `K_{eff} ≤ 4`, что и составляет содержание Теоремы 4.1.

### Шаг 4. Conditions of validity

**Constraint qualification (normal extremal):** `ν_k = 1` для всех `k`
выполняется, если матрица constraint `v` имеет полный столбцовый ранг
(в нашем случае `v ≠ 0` — тривиально). Это исключает abnormal extremals.

**Существование оптимума:** компактность `\mathcal{U}_{cb}` следует из
конечности `U^K` и непрерывности charge balance constraint
(дискретный аналог теоремы Вейерштрасса, см. Васильев § 1.3).

**Непрерывная дифференцируемость:** `F, c_k` непрерывно дифференцируемы
по `z` (Стокс — `\mathcal{C}^\infty`), что нужно для применения PMP.

## Известные риски и митигации

| Риск | Митигация |
|---|---|
| **Дискретность U нарушает применение теорем о tangent cones** | Paruchuri явно допускает `U_t` произвольным; для конечного U касательный конус превращается в discrete direction set. Это техническая аккуратность в § 4.5, не показатель некорректности. |
| **Charge balance — equality (не inequality) → constraint qualification** | Достаточно, чтобы коэффициенты `v[k] = V_{diff} TP[k]` не были все нулями — что верно для любого нетривиального waveform. |
| **`K_{eff} ≤ 4` слишком оптимистичная оценка** | Если строгое доказательство даст только `K_{eff} ≤ K_{max} = 12` (тривиальная оценка), это всё ещё *структурный* результат — мы доказываем, что оптимум *bang-bang* (не равен среднему по уровню), а не среднее по уровню как в continuous relaxation. Это уже content для главы 4. |
| **Связь с реальной физикой Стокса (нелинейность по V)** | Сделать формальную теорему для *линейной* модели, эмпирическую часть в § 7 для нелинейной (с обсуждением расхождений). |
| **Многокритериальность через ε-constraint** | На каждом срезе ε применяем PMP (§ 5.2). Структура решения на каждом срезе — bang-bang с `K_{eff} ≤ 4` (Теорема 4.1). Вся Парето-граница состоит из таких bang-bang точек. |

## Слабая (fallback) формулировка теоремы

Если строгое `K_{eff} ≤ d_{state} + 2` не получится в полном объёме, есть
два уровня отступления, каждый из которых всё ещё содержательный:

**Уровень 1 (слабее):** Теорема 4.1' — *в классе charge-balanced waveforms
оптимум имеет bang-bang структуру*; число активных фаз ≤ `K_{max} = 12`
(тривиальная оценка по архитектуре SSD1680).

→ Доказывается прямо из (PMP-v) Paruchuri без оценок размерности.
Это уже значимое утверждение: показывает, что искать средние уровни
(VSH1 → промежуточные напряжения) бесполезно — оптимум всегда на углах.

**Уровень 2 (ещё слабее):** Существует bang-bang waveform `\tilde{u}`,
такой что `J(\tilde{u}) ≤ J(u^*) + \varepsilon` для любого `ε > 0`
(плотность bang-bang в окрестности оптимума).

→ Это уже фактически следствие конечности U и стандартный аргумент
аппроксимации, не требует тонкого PMP.

Между Уровень 1 и оригинальной формулировкой — пространство для тонкой
оценки `K_{eff}`, которое можно постепенно сужать в ходе M4.

## Что проверить до начала M4

- [ ] **Проверка corner case в Theorem 3.1 Paruchuri для finite action set.**
      Авторы рассматривают непрерывные `U_t`, формально finite требует расширения.
      Возможно, в Paruchuri Appendix B (definitions of tangent cones) есть discrete case.
- [ ] **Уточнить размерность state space `d_{state}` после калибровки.**
      Если ODE-модель усложнится (например, нужны 3+ переменные на пиксель —
      позиция, скорость, ghost charge, температура), `K_{eff}` вырастет.
- [ ] **Проверить, что Lin 2024 P_peak формула корректно подставляется в `E[k]`.**
      Их `P_peak` — пиковая мощность (мгновенная), а нам нужна интегральная
      энергия `E[k] = ∫ P dt`. Это надо аккуратно вывести.
- [ ] **Проверить связь между `\arg\max H_k` и физическим waveform-переключением.**
      Hamiltonian maximization даёт `u^*[k]`, но в waveform это соответствует
      выбору source code в данной фазе. Согласовать с архитектурой LUT (12 фаз × 4
      sub-frame × 5 sub-LUT).

## Итог эскиза

**Эскиз складывается.** Все ключевые шаги опираются на доказанные теоремы
(Paruchuri 2019 Theorem 3.1, Pontryagin § 3.3, Васильев гл. 5). Открытые
вопросы — технические уточнения, не фундаментальные препятствия.

→ **Декларация:** можно начинать M4 с формулировки и полного доказательства
Теоремы 4.1 в основной формулировке. При неуспехе на отдельных шагах —
fallback на Уровень 1 (см. выше).

→ **Зависимости от других задач:** требуется завершить § 3 (модель и
калибровка) до Шага 4 доказательства, чтобы знать конкретное `d_{state}`.

## Главы для нашей работы

### Глава 1. Постановка задачи оптимального управления

- 1.1. Описание управляемого процесса: `dx/dt = f(x, u, t)`, `x ∈ ℝⁿ`,
       `u ∈ U ⊂ ℝʳ` (допустимое множество управлений).
- 1.2. Критерий качества: `J(u) = ∫₀ᵀ f⁰(x, u, t) dt + φ(x(T))` (Майер-Больца).
- 1.3. Концепция оптимального управления и оптимальной траектории.
- 1.4. Игольчатые вариации управления (key idea для доказательства PMP).
- 1.5. Виды задач: с фиксированным временем, с свободным концом, с фазовыми
       ограничениями.

**Применение в курсовой:**
- § 3 (физическая модель): формулировка нашей системы `dz/dt = f(z, u, t)`
  для одного пикселя (z — состояние частицы), `u(t) ∈ {V_min..V_max}`.
- § 4.1: дискретизация по фазам LUT — переход от непрерывной формулировки
  Понтрягина к дискретной задаче.

### Глава 2. Принцип максимума Понтрягина — формулировка и доказательство

- 2.1. Сопряжённая система: `dψ/dt = -∂H/∂x`, где `H = ψ·f + ψ⁰·f⁰`.
- 2.2. **Принцип максимума:** для оптимального управления `u*(t)`
       `H(x*, u*, ψ, t) = max_{u ∈ U} H(x*, u, ψ, t)` для почти всех `t`.
- 2.3. Граничные условия трансверсальности на сопряжённую переменную.
- 2.4. Условия в случае фиксированного или свободного концевого момента T.
- 2.5. Доказательство через игольчатые вариации (центральный технический
       момент).
- 2.6. Случай линейной по управлению системы: bang-bang управление.

**Применение в курсовой:**
- § 4.4: применение принципа максимума к нашему дискретному функционалу.
- § 4.5 (наша Теорема 4.1): использование вывода о bang-bang структуре
  для случая линейной по управлению модели (что выполнено при кусочно-
  линейной аппроксимации Стокса по управляющему напряжению).
- § 4.6 (следствия): связь между числом «переключений» оптимального
  bang-bang управления и размерностью пространства сопряжённых
  переменных.

## Структурное различие с дискретной версией (Paruchuri 2019)

Понтрягин — для **непрерывного времени**, наша задача — **дискретная**
по фазам LUT. Прямой перенос невозможен по двум причинам:
1. Дискретное множество допустимых управлений `U = {VSH1, VSH2, VSL, VCOM, 0}`
   не выпукло, что нарушает classical proof (игольчатые вариации требуют
   возможности «вставки» произвольно малого отрезка).
2. Constraint на frequency / structure waveform добавляет ограничение,
   которое не покрывается классическим PMP.

Эти два ограничения снимает работа Paruchuri & Chatterjee (2019, IEEE TAC) —
см. `docs/notes/paruchuri.md`. Понтрягин даёт intuition, Paruchuri даёт
формальный аппарат для нашего случая.
